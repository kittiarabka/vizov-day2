# Протокол доверия

Программа на JavaScript отбирает безопасные сигналы Багги, сортирует их по приоритету и решает, сменит ли Кристальный Страж протокол.

HTML нет. Сторонние библиотеки не нужны.

## Запуск

Нужен [Node.js](https://nodejs.org/).

1. Распакуй архив.
2. Открой терминал в папке с `script.js`.
3. Запусти:

```bash
node script.js
```

Результат появится в консоли.

## Что выводится

```text
Безопасные сигналы: [...]
Сигналы по приоритету: [...]
Названия сигналов: [...]
Уровень доверия: 85
Новый протокол Стража: Доверять
```

Для исходных данных в файле это четыре безопасных сигнала. Опасные в сумму не входят. Доверие считается так: стартовые 15 плюс очки безопасных сигналов. Порог 80, поэтому протокол становится «Доверять».
